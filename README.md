# 架け橋パートナーズ コーポレートサイト(制作サンプル)

大阪の人材紹介会社「株式会社 架け橋パートナーズ」を想定したコーポレートサイトです。
**架空の会社を想定した制作サンプル**で、社名・数字・人名・求人・事例・声はすべて仮置きです。

- テーマ:「点と点が、線になる」— ティール(企業)× コーラル(人)
- 構成:HTML / CSS / **Vanilla JavaScript**(フレームワーク・ライブラリなし、ビルド不要)

## ページ

| ページ | パス | 主に読む人 | フォーム |
| --- | --- | --- | --- |
| トップ | `/` | 企業 | 採用のご相談 |
| 人材紹介サービス | `/service/` | 企業 | 採用のご相談 |
| 求人情報 | `/jobs/` | 求職者 | 無料の転職相談 |
| 企業概要 | `/company/` | 共通 | — |
| 送信完了 | `/thanks/` | 送信した人(noindex) | — |
| プライバシーポリシー | `/privacy/` | — | — |

## ファイル構成

```
index.html            トップ
service/ jobs/ company/ thanks/ privacy/   各ページ(index.html)
assets/css/style.css  デザイントークン・全スタイル
assets/js/main.js     メニュー/スクロールの線/出現演出/カウントアップ/フォーム/求人カード/計測
assets/js/hero.js     ファーストビューの3D演出(Canvas 2D + 自前の透視投影)
assets/img/           画像(Geminiで生成したイラスト)
robots.txt sitemap.xml
```

## 実装のポイント

- **ファーストビューの3D**:three.js を使わず、Canvas 2D に自前で透視投影して描画。点が1組ずつ線で結ばれ、つながった瞬間に光る(1秒に3回以下)。ゆっくり回転し、マウスで傾く。画面外・タブ非表示で停止、スマホでは点を減らす
- **セクションをつなぐ線**:ティール→コーラルの1本の線がスクロールに合わせて伸び、各セクションの見出しで点がともる
- **求人カード**:「あなた」の点から各カードへ線が伸びて順に出現。「この求人について相談する」で、求職者フォームの「気になる求人」に自動で入る(`?job=J-002` でも可)
- **フォーム**:必須・メール・電話・添付(PDF/Word、2ファイル・合計5MB)をその場でチェック。見えない入力欄と送信間隔の制限で迷惑送信を対策。サンプルのため実際には送信せず `/thanks/` へ移動
- **計測**:`dataLayer` に `generate_lead` / `form_start` / `cta_click` / `job_click` / `job_consult` / `tel_click` を送信(個人情報は送らない)。公開時に GTM を読み込む
- **アクセシビリティ**:コントラスト4.5:1以上、タップ領域44px以上、キーボード操作、`prefers-reduced-motion` で動きを停止(ファーストビューは静止画)
- **JavaScriptなしでも**:内容・求人の詳細・フォームはすべて表示される
- **SEO**:ページごとの title / description / canonical / OGP、`Organization` と `BreadcrumbList` の構造化データ

## ローカルで見る

```bash
python3 -m http.server 5173
```

http://localhost:5173/ を開きます。
